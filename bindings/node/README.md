# bindings/node

TypeScript bindings via napi-rs: `Instance` class managing multiple isolated
handles with query/mutate, plus a generated multi-platform loader.

## Build and test (local, no publish)

```sh
cd bindings/node
npm install
npx napi build --platform   # emits index.js, index.d.ts, *.node
node --test test/
```

`index.js` / `index.d.ts` are generated by the napi CLI from `src/lib.rs`
rustdoc — never hand-edit them; rerun the build instead.
